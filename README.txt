
백마고주파 기업 웹사이트 시안
===========================

구성 파일
- index.html: 메인 페이지
- company.html: 회사소개
- technology.html: 기술력
- solutions.html: 솔루션/제품
- applications.html: 적용분야
- projects.html: 프로젝트 사례
- contact.html: 문의
- assets/css/style.css: 전체 스타일
- assets/js/main.js: 모바일 메뉴 및 문의 폼 데모 스크립트
- assets/images/: 로고 및 생성형 실사 스타일 이미지 자산

사용 방법
1. 압축을 해제합니다.
2. index.html을 브라우저에서 열면 정적 웹사이트를 확인할 수 있습니다.
3. 실제 운영 시 contact.html의 문의 폼은 이메일 발송, 게시판, CRM, 카카오톡 상담 등으로 연동해야 합니다.
4. 회사 정보, 인증, 설비 사진, 납품 사례는 실제 자료로 교체하면 더 정확합니다.

디자인 방향
- 고주파 시스템 전문 기업의 신뢰감, 정밀 기술력, 품질 안정성, 현장 적용성을 강조했습니다.
- 중복 이미지 없이 각 섹션별로 다른 실사형 산업 이미지를 적용했습니다.
- PC/태블릿/모바일 반응형으로 제작했습니다.
